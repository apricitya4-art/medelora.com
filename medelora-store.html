    النطاقات الفرعية الثلاثة

    تُنشأ بعد ربط الدومين بـ Cloudflare، بسجلّ DNS واحد لكل نطاق. انسخ السجلّ كما هو والصقه في لوحة Cloudflare تحت DNS → Records → Add record.

    الاستضافة المجانية والإطلاق

    الخطة: ملفات المتجر على GitHub Pages، والدومين وشهادة HTTPS والحماية عبر Cloudflare — بدون أي اشتراك مدفوع.

    GitHub Pages

    يستضيف ملفات الموقع — حسابك: apricitya4-art

    1. أنشئ مستودعاً جديداً باسم medelora-store.
    2. ارفع ملفات المتجر (index.html ومجلد assets) إلى الفرع main.
    3. من Settings → Pages اختر النشر من فرع main والمجلد الجذر.
    4. أضف ملف CNAME يحتوي سطراً واحداً: medelora.com.

    Cloudflare

    يربط الدومين بالموقع ويؤمّنه بـ HTTPS

    2. في Spaceship، استبدل الـ nameservers الحالية (ns1/ns2.atom.com) باسمي الخوادم اللذين يعطيهما Cloudflare.
    3. أضف سجلّات DNS: سجلّات GitHub Pages للنطاق الرئيسي، وسجلّ CNAME لكل نطاق فرعي.
    4. فعّل Always Use HTTPS من إعدادات SSL/TLS.
